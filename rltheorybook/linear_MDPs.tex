\chapter{Linearly Parameterized MDPs}
\label{chap:linear_MDPs}

This chapter studies strategic exploration in episodic finite-horizon MDPs under a
\emph{linear transition model}. The goal is to obtain regret bounds that scale
polynomially in the feature dimension $d$ (and the horizon $H$), without explicit
dependence on the number of states.

The algorithmic template mirrors tabular UCBVI (Chapter~\ref{chap:tabular_exploration}):
build an optimistic model from the data, plan via value iteration in that model,
execute the resulting policy for one episode, and repeat. The main new ingredient is
that we cannot estimate a full transition table; instead, we must estimate the
one-step lookahead terms needed by dynamic programming through a regression primitive
based on known features.


A recurring theme from Chapter~\ref{chap:linear_features} is that linear features lead to
$\poly(d)$ guarantees only under a \emph{closure} condition: the regression targets created by
dynamic programming must remain learnable from the available data (Bellman completeness).
The linear transition model we assume here enforces a \emph{stronger} version of this idea for
the transition component: regardless of how nonlinear the value function may be, its one-step
lookahead under the true dynamics can still be represented linearly in the features. This is
what makes the least-squares steps inside optimistic value iteration genuinely well-specified,
even though the targets depend on the algorithm's own value estimates.

A common strengthening of the model additionally assumes that rewards are also linear in the
same features. Under that assumption, the \emph{entire} Bellman backup (reward plus transition)
is closed over a linear class, aligning exactly with the linear Bellman completeness condition
from Chapter~\ref{chap:linear_features}. In this chapter we keep rewards known to isolate the
main statistical difficulty: learning transition effects from trajectory data.

\section{Setting: online episodic learning and regret}
\label{sec:linear_mdp_setting}

We adopt the episodic protocol and regret criterion from
Chapter~\ref{chap:tabular_exploration}.  The MDP has horizon $H$, state space $\Scal$
(possibly very large but finite, so matrix notation is well-defined), action space
$\Acal$, and a fixed start state $s_0$.  Transitions are stage-dependent:
$\{P_h^\star(\cdot\mid s,a)\}_{h=0}^{H-1}$.

Rewards are deterministic, known, and bounded:
\[
r_h(s,a)\in[0,1]\qquad\text{for all }h\in\{0,\dots,H-1\},\ (s,a)\in\Scal\times\Acal.
\]
(Unknown and/or stochastic rewards can be handled by empirical means plus an
additional Hoeffding-style bonus; we suppress this to keep the focus on learning
the transitions.)

A learning algorithm runs for $K$ episodes.  In episode $k$, it chooses a (possibly
history-dependent) nonstationary policy $\pi^k=\{\pi_h^k\}_{h=0}^{H-1}$, then executes it to
generate a trajectory
\[
s_0^k=s_0,\qquad a_h^k=\pi_h^k(s_h^k),\qquad s_{h+1}^k\sim P_h^\star(\cdot\mid s_h^k,a_h^k),
\qquad h=0,\dots,H-1.
\]

For any policy $\pi$, define the stage-$h$ value in the true MDP as
\[
V_h^\pi(s)
:= \E\!\left[\sum_{t=h}^{H-1} r_t(s_t,a_t)\ \middle|\ s_h=s,\ \pi,\ P^\star \right],
\qquad
V_h^\star(s):=\max_{\pi}V_h^\pi(s).
\]
We abbreviate $V^\pi:=V_0^\pi(s_0)$ and $V^\star:=V_0^\star(s_0)$.

The (pseudo-)regret over $K$ episodes is
\[
R_K \;:=\; \E\!\left[\sum_{k=0}^{K-1}\bigl(V^\star - V^{\pi^k}\bigr)\right].
\]

We will also use the stage-$h$ occupancy measure (defined as in
Chapter~\ref{chap:tabular_exploration}): for a policy $\pi$,
\[
d_h^\pi(s,a) := \Pr(s_h=s,\,a_h=a\mid s_0,\pi,P^\star).
\]

\section{Linear MDP model}
\label{sec:linear_mdp_model}

We assume the transition kernel is \emph{linear in known features}.  Let
$\phi:\Scal\times\Acal\to\R^d$ be a known feature map.

\begin{assumption}[Linear transition model]\label{assump:linear_mdp}
There exists a feature map $\phi:\Scal\times\Acal\to\R^d$ with
$\sup_{s,a}\|\phi(s,a)\|_2\le 1$, and unknown parameters
$\{\mu_h^\star\}_{h=0}^{H-1}$, where each $\mu_h^\star\in\R^{|\Scal|\times d}$, such that
for all $h$ and $(s,a)$,
\[
P_h^\star(\cdot\mid s,a) \;=\; \mu_h^\star\,\phi(s,a),
\]
and the right-hand side is a valid probability distribution on $\Scal$.

Moreover, we assume the (normalization) bound
\[
\big\|(\mu_h^\star)^\top f\big\|_2 \;\le\; \sqrt{d}\,\|f\|_\infty
\qquad \text{for all } f:\Scal\to\R \text{ and all } h\in\{0,\dots,H-1\}.
\]
\end{assumption}

Assumption~\ref{assump:linear_mdp} induces a low-rank structure: viewing the transition model
as a matrix mapping state--action pairs to next-state distributions, its rank is at most $d$.
Tabular MDPs are recovered by taking $\phi$ to be the one-hot encoding of $(s,a)$, in which
case $d=|\Scal||\Acal|$ and the model becomes unconstrained.

The only role of the operator-norm condition above is to control the size of certain
linear coefficients that represent Bellman backups; it is a convenient normalization and
can be replaced by a generic constant if desired.

\section{A key property: Bellman backups are linear in features}
\label{sec:linear_mdp_backup_is_linear}

A basic consequence of Assumption~\ref{assump:linear_mdp} is that, for any bounded
$f:\Scal\to\R$, the conditional expectation $(P_h^\star f)(s,a)$ is linear in $\phi(s,a)$.

\begin{lemma}[Linearization of $P_h^\star f$]\label{lem:linearize_Pf}
Fix a stage $h$ and a function $f:\Scal\to\R$.  Define
\[
w_{h,f}^\star \;:=\; (\mu_h^\star)^\top f \in \R^d.
\]
Then for all $(s,a)$,
\[
(P_h^\star f)(s,a)
:= \E_{s'\sim P_h^\star(\cdot\mid s,a)}[f(s')]
\;=\;
\phi(s,a)^\top w_{h,f}^\star.
\]
Moreover, if $\|f\|_\infty\le H$ then $\|w_{h,f}^\star\|_2\le H\sqrt{d}$.
\end{lemma}

\begin{proof}
By Assumption~\ref{assump:linear_mdp}, $P_h^\star(\cdot\mid s,a)=\mu_h^\star\phi(s,a)$, hence
\[
(P_h^\star f)(s,a) = \sum_{s'\in\Scal} f(s')\,P_h^\star(s'\mid s,a)
= f^\top \mu_h^\star \phi(s,a)
= \phi(s,a)^\top (\mu_h^\star)^\top f
= \phi(s,a)^\top w_{h,f}^\star.
\]
The norm bound follows from the second part of Assumption~\ref{assump:linear_mdp}:
$\|w_{h,f}^\star\|_2=\|(\mu_h^\star)^\top f\|_2\le \sqrt d\,\|f\|_\infty\le H\sqrt d$.
\end{proof}

If the transition parameters $\{\mu_h^\star\}$ were known, the optimal values could be
computed by backward dynamic programming:
\[
V_H^\star\equiv 0,\qquad
Q_h^\star(s,a)=r_h(s,a)+(P_h^\star V_{h+1}^\star)(s,a),\qquad
V_h^\star(s)=\max_{a\in\Acal}Q_h^\star(s,a).
\]
Lemma~\ref{lem:linearize_Pf} shows that, even though $V_{h+1}^\star$ need not be linear,
the function $(s,a)\mapsto (P_h^\star V_{h+1}^\star)(s,a)$ is always linear in $\phi(s,a)$.
Thus, the central statistical problem is to estimate linear functionals
$(P_h^\star f)(s,a)$ accurately for the value functions $f$ encountered during planning.

\paragraph{Remark (a strong form of completeness: \emph{all} functions back up into the span).}
Lemma~\ref{lem:linearize_Pf} can be read as the key ``completeness'' property
behind this model.  In Chapter~\ref{chap:linear_features}, Bellman completeness
was phrased as a closure requirement of the form
$f\in\Fcal \Rightarrow \Tcal_h f\in\Fcal$ for a chosen linear class $\Fcal$.
Here we assume something even stronger for the transition component: for each
stage $h$, the map
\[
f:\Scal\to\R
\quad\longmapsto\quad
\bigl((s,a)\mapsto (P_h^\star f)(s,a)\bigr)
\]
takes \emph{every bounded} $f$ (not just linear ones) into $\mathrm{span}(\phi)$.
This is exactly what makes least-squares estimation viable even when the value
functions we plug in --- such as $V_{h+1}^\star$ or the optimistic iterates
$\widehat V_{h+1}^k$ --- are highly nonlinear (they involve $\max$ over actions and
clipping).  The algorithm never needs $f$ itself to be linear; it only needs the
one-step conditional expectation $P_h^\star f$ to admit a linear representation
in $\phi(s,a)$.

\section{Lin-UCBVI: ridge regression and optimistic planning}
\label{sec:linear_mdp_ucbvi}

We now define a ridge-regression primitive for estimating $(P_h^\star f)(s,a)$ and use it
to construct an optimistic value-iteration algorithm in the spirit of UCBVI.

\subsection{Stage-wise ridge regression for $(P_h^\star f)(s,a)$}
\label{subsec:linear_mdp_ridge_pf}

Fix a regularization parameter $\lambda>0$.  For each episode $k$ and stage $h$, define the
pre-episode-$k$ dataset at stage $h$:
\[
D_h^k := \{(s_h^i,a_h^i,s_{h+1}^i)\}_{i=0}^{k-1}.
\]
Let $x_h^i:=\phi(s_h^i,a_h^i)\in\R^d$ and define the regularized design matrix
\[
\Lambda_h^k \;:=\; \lambda I + \sum_{i=0}^{k-1} x_h^i (x_h^i)^\top.
\]
Given any function $f:\Scal\to\R$, define the ridge estimator of the linear coefficient
$w_{h,f}^\star=(\mu_h^\star)^\top f$ by
\[
\widehat w_{h,f}^k
\;:=\;
(\Lambda_h^k)^{-1}\sum_{i=0}^{k-1} x_h^i\,f(s_{h+1}^i),
\qquad
(\widehat P_h^k f)(s,a)
\;:=\;
\phi(s,a)^\top \widehat w_{h,f}^k.
\]
The algorithm will only use $\widehat P_h^k$ through such linear functionals $(\widehat P_h^k f)(s,a)$.

\subsection{Optimistic planning and policy selection}
\label{subsec:linear_mdp_ucbvi_alg}

Fix a bonus scale $\beta>0$ and define the (UCB-style) exploration bonus
\[
b_h^k(s,a) \;:=\; \beta\,\|\phi(s,a)\|_{(\Lambda_h^k)^{-1}}
\qquad\text{where}\qquad
\|u\|_{(\Lambda_h^k)^{-1}}:=\sqrt{u^\top(\Lambda_h^k)^{-1}u}.
\]
(We will later choose $\beta$ using a uniform confidence bound over the random value
functions produced by the algorithm.)

Define the stage-dependent clipping operator
\[
\mathrm{clip}_{[0,H-h]}(x):=\min\{H-h,\max\{0,x\}\}.
\]
At the start of episode $k$, Lin-UCBVI computes optimistic $Q$- and value-functions by a
backward recursion.  Initialize $\widehat V_H^k(\cdot)\equiv 0$, and for $h=H-1,\dots,0$
define
\begin{align}
\widehat Q_h^k(s,a)
&:=
\mathrm{clip}_{[0,H-h]}\!\left(
r_h(s,a) + b_h^k(s,a) + (\widehat P_h^k \widehat V_{h+1}^k)(s,a)
\right),
\label{eq:ucbvi_lin_Q}\\
\widehat V_h^k(s)
&:= \max_{a\in\Acal}\widehat Q_h^k(s,a),
\qquad
\pi_h^k(s)\in\arg\max_{a\in\Acal}\widehat Q_h^k(s,a).
\label{eq:ucbvi_lin_V}
\end{align}
The policy $\pi^k=\{\pi_h^k\}_{h=0}^{H-1}$ is then executed for one episode and the
design matrices are updated.

\begin{algorithm}[t]
\begin{algorithmic}[1]
\Require horizon $H$, episodes $K$, regularization $\lambda>0$, bonus scale $\beta>0$
\State Initialize $\Lambda_h^0 \gets \lambda I$ for all $h\in\{0,\dots,H-1\}$.
\For{$k=0,1,\dots,K-1$}
    \State Set $\widehat V_H^k(\cdot)\equiv 0$.
    \For{$h=H-1,H-2,\dots,0$}
        \State Compute $\widehat w_{h,\widehat V_{h+1}^k}^k
        \gets (\Lambda_h^k)^{-1}\sum_{i=0}^{k-1}\phi(s_h^i,a_h^i)\,\widehat V_{h+1}^k(s_{h+1}^i)$.
        \State Define $(\widehat P_h^k\widehat V_{h+1}^k)(s,a)=\phi(s,a)^\top \widehat w_{h,\widehat V_{h+1}^k}^k$.
        \State Define $\widehat Q_h^k$ by \eqref{eq:ucbvi_lin_Q}, and then $\widehat V_h^k,\pi_h^k$ by \eqref{eq:ucbvi_lin_V}.
    \EndFor
    \State Execute $\pi^k$: $s_0^k=s_0$; for $h=0,\dots,H-1$, play $a_h^k=\pi_h^k(s_h^k)$ and sample
    $s_{h+1}^k\sim P_h^\star(\cdot\mid s_h^k,a_h^k)$.
    \For{$h=0,1,\dots,H-1$}
        \State Update $\Lambda_h^{k+1}\gets \Lambda_h^k + \phi(s_h^k,a_h^k)\phi(s_h^k,a_h^k)^\top$.
    \EndFor
\EndFor
\end{algorithmic}
\caption{Lin-UCBVI (least-squares value iteration with UCB bonus)}
\label{alg:lin_ucbvi}
\end{algorithm}

We assume the maximization over $a\in\Acal$ in \eqref{eq:ucbvi_lin_V} is tractable (e.g.,
finite $\Acal$ or access to an appropriate optimization oracle).

\section{Regret guarantee and analysis}
\label{sec:linear_mdp_analysis}

We now bound the expected regret of Lin-UCBVI.  The argument mirrors tabular UCBVI:
a uniform confidence statement for the value-dependent regression targets, an optimism
lemma, a one-episode performance decomposition, and an elliptical-potential summation.

\begin{theorem}[Regret of Lin-UCBVI]\label{thm:ucbvi_lin_regret}
Assume the linear transition model (Assumption~\ref{assump:linear_mdp}) and bounded rewards
$r_h(s,a)\in[0,1]$.  Run Lin-UCBVI (Algorithm~\ref{alg:lin_ucbvi}) with regularization
$\lambda\ge 1$ and bonus
\[
b_h^k(s,a)=\beta\,\|\phi(s,a)\|_{(\Lambda_h^k)^{-1}}.
\]

Fix $\delta\in(0,1)$.  Suppose $\beta$ is chosen so that the uniform confidence event in
Proposition~\ref{prop:uniform_model_conf} holds with probability at least $1-\delta$.
Then the expected regret satisfies
\[
R_K
\;=\;
\E\!\left[\sum_{k=0}^{K-1}\bigl(V^\star - V^{\pi^k}\bigr)\right]
\;\le\;
c\,\beta\,H\,\sqrt{K\,d\,\log\!\Big(1+\tfrac{K}{\lambda}\Big)}
\;+\;
\delta K H,
\]
for a universal constant $c>0$.

In particular, one may take $\beta=\beta_{K,\delta/H}$ as in
Corollary~\ref{cor:uniform_model_conf_bonus_class} (applied stage-wise and union-bounded over $h$),
which yields $\beta=\widetilde O(Hd)$ and hence
$R_K=\widetilde O\!\big(H^2\sqrt{d^3K}\big)$.
\end{theorem}

\subsection{Uniform confidence for the value-dependent targets}

For each stage $h$, the algorithm fits ridge regression using samples
$\{(s_h^i,a_h^i,s_{h+1}^i)\}_{i<k}$ and then queries the fitted model at the
\emph{random} value function $f=\widehat V_{h+1}^k$.  The next proposition is exactly the
uniformization step that justifies the UCB bonus.

\begin{proposition}[Uniform model confidence]\label{prop:uniform_model_conf}
Fix $\delta\in(0,1)$.  With probability at least $1-\delta$, simultaneously for all
episodes $k\in\{0,\dots,K-1\}$, all stages $h\in\{0,\dots,H-1\}$, all $(s,a)\in\Scal\times\Acal$,
and for $f=\widehat V_{h+1}^k$ produced by Lin-UCBVI,
\[
\big|(\widehat P_h^k f)(s,a) - (P_h^\star f)(s,a)\big|
\;\le\;
\beta\,\|\phi(s,a)\|_{(\Lambda_h^k)^{-1}}.
\]
\end{proposition}

\begin{proof}
Fix a stage $h$.  Consider the optimistic value-function class $\Fcal$ from
Lemma~\ref{lem:cover_optimistic_value_class_app} (Appendix~\ref{app:covering_uniformization}),
with parameters chosen large enough to contain the algorithm's iterates:
\begin{itemize}
\item the known reward offset $r_h(s,a)$ is handled by the remark in
Lemma~\ref{lem:cover_optimistic_value_class_app};
\item max and clipping commute and clipping is a $\|\cdot\|_\infty$ contraction
(Lemma~\ref{lem:max_clip_contraction_app});
\item and for all $k,h$ one has the deterministic bound
$\|\widehat w_{h,\widehat V_{h+1}^k}^k\|_2 \le \frac{1}{\lambda}\sum_{i<k}\|\phi(s_h^i,a_h^i)\|_2\,
\|\widehat V_{h+1}^k\|_\infty \le HK/\lambda$, so we may take $L=HK/\lambda$.
\end{itemize}
Under Assumption~\ref{assump:linear_mdp}, the linear conditional expectation condition
\eqref{eq:linear_model_stage_h} in Corollary~\ref{cor:uniform_model_conf_bonus_class} holds with
$w_f^\star=(\mu_h^\star)^\top f$ and $\|w_f^\star\|_2\le H\sqrt d$ (Lemma~\ref{lem:linearize_Pf}).

Apply Corollary~\ref{cor:uniform_model_conf_bonus_class} at this stage with failure probability
$\delta/H$, then take a union bound over $h\in\{0,\dots,H-1\}$.  This yields the stated event.
\end{proof}

For the remainder of the analysis we condition on the event in
Proposition~\ref{prop:uniform_model_conf}.

\subsection{Optimism and a one-episode bound}

\begin{lemma}[Optimism]\label{lem:ucbvi_lin_optimism}
On the event of Proposition~\ref{prop:uniform_model_conf}, for every episode $k$, stage $h$,
and state $s$,
\[
\widehat V_h^k(s)\ \ge\ V_h^\star(s).
\]
\end{lemma}

\begin{proof}
Fix episode $k$ and argue by backward induction on $h$.
At $h=H$, $\widehat V_H^k\equiv 0 = V_H^\star$.
Assume $\widehat V_{h+1}^k\ge V_{h+1}^\star$ pointwise.

Fix $(s,a)$.  Since $P_h^\star(\cdot\mid s,a)$ is a distribution and
$\widehat V_{h+1}^k\ge V_{h+1}^\star$, we have
$(P_h^\star V_{h+1}^\star)(s,a)\le (P_h^\star \widehat V_{h+1}^k)(s,a)$.
By Proposition~\ref{prop:uniform_model_conf} applied to $f=\widehat V_{h+1}^k$,
\[
(P_h^\star \widehat V_{h+1}^k)(s,a)
\le
(\widehat P_h^k \widehat V_{h+1}^k)(s,a) + b_h^k(s,a).
\]
Therefore,
\[
Q_h^\star(s,a)
=
r_h(s,a) + (P_h^\star V_{h+1}^\star)(s,a)
\le
r_h(s,a) + b_h^k(s,a) + (\widehat P_h^k\widehat V_{h+1}^k)(s,a).
\]
Since $Q_h^\star(s,a)\in[0,H-h]$, clipping to $[0,H-h]$ preserves the inequality and gives
$Q_h^\star(s,a)\le \widehat Q_h^k(s,a)$.  Taking maxima over $a$ yields
$V_h^\star(s)\le \widehat V_h^k(s)$.
\end{proof}

\begin{lemma}[Per-episode bonus bound]\label{lem:ucbvi_lin_per_episode}
On the event of Proposition~\ref{prop:uniform_model_conf}, for every episode $k$,
\[
V^\star - V^{\pi^k}
\;\le\;
2\sum_{h=0}^{H-1}\E_{(s_h,a_h)\sim d_h^{\pi^k}}\!\big[b_h^k(s_h,a_h)\big].
\]
\end{lemma}

\begin{proof}
Fix episode $k$ and abbreviate $\pi=\pi^k$, $\widehat V_h=\widehat V_h^k$, $\widehat P_h=\widehat P_h^k$,
$b_h=b_h^k$.  Optimism (Lemma~\ref{lem:ucbvi_lin_optimism}) gives
$V^\star - V^\pi \le \widehat V_0(s_0)-V^\pi$.
Define $\Delta_h(s):=\widehat V_h(s)-V_h^\pi(s)$, so $\Delta_H\equiv 0$.

On the confidence event, $(\widehat P_h\widehat V_{h+1})(s,a)\ge (P_h^\star\widehat V_{h+1})(s,a)-b_h(s,a)\ge -b_h(s,a)$,
so $r_h(s,a)+b_h(s,a)+(\widehat P_h\widehat V_{h+1})(s,a)\ge r_h(s,a)\ge 0$ and the clipping can only decrease the expression. Now, for any state $s$ at stage $h$, using that $\pi_h(s)\in\arg\max_a \widehat Q_h(s,a)$ and that
$\widehat Q_h$ is obtained by clipping the Bellman-style expression, we have
\[
\widehat V_h(s)
=
\widehat Q_h\bigl(s,\pi_h(s)\bigr)
\le
r_h\bigl(s,\pi_h(s)\bigr) + b_h\bigl(s,\pi_h(s)\bigr)
+ (\widehat P_h \widehat V_{h+1})\bigl(s,\pi_h(s)\bigr).
\]
On the other hand,
\[
V_h^\pi(s)= r_h\bigl(s,\pi_h(s)\bigr) + (P_h^\star V_{h+1}^\pi)\bigl(s,\pi_h(s)\bigr).
\]
Subtracting and writing $\widehat V_{h+1}=V_{h+1}^\pi+\Delta_{h+1}$ yields
\[
\Delta_h(s)
\le
b_h\bigl(s,\pi_h(s)\bigr)
+\bigl((\widehat P_h-P_h^\star)\widehat V_{h+1}\bigr)\bigl(s,\pi_h(s)\bigr)
+\bigl(P_h^\star \Delta_{h+1}\bigr)\bigl(s,\pi_h(s)\bigr).
\]
Take expectations along a trajectory of $\pi$ in the true MDP and unroll from $h=0$ to $H-1$
(using $\Delta_H\equiv 0$) to obtain
\[
\widehat V_0(s_0)-V^\pi
\le
\sum_{h=0}^{H-1}\E_{d_h^\pi}\!\left[
b_h(s_h,a_h) + \bigl((\widehat P_h-P_h^\star)\widehat V_{h+1}\bigr)(s_h,a_h)
\right].
\]
Finally, Proposition~\ref{prop:uniform_model_conf} implies
$\big|\big((\widehat P_h-P_h^\star)\widehat V_{h+1}\big)(s,a)\big|\le b_h(s,a)$, and the claim follows.
\end{proof}

\subsection{Summation via an elliptical potential}

\begin{proof}[Proof of Theorem~\ref{thm:ucbvi_lin_regret}]
Let $\mathcal E$ denote the event in Proposition~\ref{prop:uniform_model_conf}.
On $\mathcal E$, Lemma~\ref{lem:ucbvi_lin_per_episode} implies that for each episode $k$,
\[
V^\star - V^{\pi^k}
\le
2\sum_{h=0}^{H-1}\E\!\left[b_h^k(s_h^k,a_h^k)\mid \mathcal H_{<k}\right],
\]
since $b_h^k$ is $\mathcal H_{<k}$-measurable and $(s_h^k,a_h^k)$ has occupancy distribution under $\pi^k$ in the true MDP.
Therefore, using $\mathbf 1\{\mathcal E\}\le 1$ and the tower property,
\[
\E\!\left[\mathbf 1\{\mathcal E\}\sum_{k=0}^{K-1}(V^\star - V^{\pi^k})\right]
\le
2\,\E\!\left[\sum_{k=0}^{K-1}\sum_{h=0}^{H-1} b_h^k(s_h^k,a_h^k)\right].
\]
Substituting $b_h^k(s,a)=\beta\|\phi(s,a)\|_{(\Lambda_h^k)^{-1}}$ gives
\[
\E\!\left[\mathbf 1\{\mathcal E\}\sum_{k=0}^{K-1}(V^\star - V^{\pi^k})\right]
\le
2\beta\sum_{h=0}^{H-1}\E\!\left[\sum_{k=0}^{K-1}\|\phi(s_h^k,a_h^k)\|_{(\Lambda_h^k)^{-1}}\right].
\]
Fix a stage $h$ and write $x_k:=\phi(s_h^k,a_h^k)$ and $\Lambda_k:=\Lambda_h^k$, so
$\Lambda_{k+1}=\Lambda_k+x_kx_k^\top$ and $\Lambda_0=\lambda I$.  Since $\lambda\ge 1$ and $\|x_k\|_2\le 1$,
we have $\|x_k\|_{\Lambda_k^{-1}}^2\le 1$.  The standard log-determinant argument (matrix determinant lemma;
see Lemma~\ref{lem:volumechange} in Chapter~\ref{chap:bandits}) gives
\[
\sum_{k=0}^{K-1}\|x_k\|_{\Lambda_k^{-1}}^2
\le
2\log\!\frac{\det(\Lambda_K)}{\det(\Lambda_0)}.
\]
Moreover, $\Lambda_K=\lambda I+\sum_{k=0}^{K-1}x_kx_k^\top \preceq (\lambda+K)I$, hence
$\det(\Lambda_K)/\det(\Lambda_0)\le (1+K/\lambda)^d$ and therefore
\[
\sum_{k=0}^{K-1}\|x_k\|_{\Lambda_k^{-1}}^2
\le
2d\log\!\Big(1+\tfrac{K}{\lambda}\Big).
\]
By Cauchy--Schwarz,
\[
\sum_{k=0}^{K-1}\|x_k\|_{\Lambda_k^{-1}}
\le
\sqrt{K\sum_{k=0}^{K-1}\|x_k\|_{\Lambda_k^{-1}}^2}
\le
\sqrt{2K\,d\,\log\!\Big(1+\tfrac{K}{\lambda}\Big)}.
\]
Summing this bound over $h=0,\dots,H-1$ yields, on $\mathcal E$,
\[
\sum_{k=0}^{K-1}\bigl(V^\star - V^{\pi^k}\bigr)
\le
c\,\beta\,H\,\sqrt{K\,d\,\log\!\Big(1+\tfrac{K}{\lambda}\Big)}
\]
for a universal constant $c>0$.

On the complement $\overline{\mathcal E}$ we use $0\le V^\star - V^{\pi^k}\le H$ to obtain
\[
\E\!\left[\mathbf 1\{\overline{\mathcal E}\}\sum_{k=0}^{K-1}\bigl(V^\star - V^{\pi^k}\bigr)\right]
\le
\Pr(\overline{\mathcal E})\cdot KH
\le
\delta K H.
\]
Combining completes the proof.
\end{proof}

\section{Bibliographic Remarks and Further Readings}

There are several ways to impose linear structure on an MDP so that learning can be
statistically and computationally efficient.  A useful organizing viewpoint, developed in
\citet{jiang2017contextual}, is that many such models have low Bellman rank (and related
complexity measures such as witness rank \citep{sun2019model}); we return to these notions
in Chapter~\ref{chap:Bellman_rank}.

The specific linear transition model used in this chapter, in which
$P_h(\cdot\mid s,a)=\mu_h^\star \phi(s,a)$, was introduced and analyzed in \citet{jin2020provably},
building on earlier algorithmic developments for linearly parameterized MDPs in
\citet{yang2019reinforcement,yang2019sample}.  A notable feature of this model is that the
unknown parameter $\mu_h^\star$ has ambient size $S\times d$, yet regret bounds can depend
polynomially on $d$ (and $H$) without explicit dependence on $S$.  In particular, the algorithm
never needs to estimate the full transition model; it only estimates the linear functionals
$(P_h^\star f)(s,a)$ required by planning.

A different family of models parameterizes the transition probabilities directly as linear
combinations of known features $\phi(s,a,s')$; see, for example,
\citet{lin_comb_model_est,pmlr-v120-jia20a,ayoub2020,zhou2020provably}.  These models
typically have $O(d)$ free parameters in the transition model, while the model
$P_h(\cdot\mid s,a)=\mu_h^\star \phi(s,a)$ has $S\cdot d$ free parameters.  The two viewpoints
are therefore not directly comparable: smaller ambient parameter count does not by itself
determine learnability or the sharp dependence on $(d,H)$ in regret.

The style of model-based implementation we use here—estimating only the Bellman-relevant
linear predictions rather than a full model—appears in related forms in other settings; see
\citet{lykouris2019corruption} for an example in the context of adversarial corruption.

Finally, extensions beyond finite-dimensional features (e.g.\ RKHS settings) typically replace
the dimension parameter $d$ by an information-gain quantity; see \citet{agarwal2020pc} for one
such development.
